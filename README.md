# ⛩️ 歴たび (Rekitabi) - 全国パワースポット参拝帳 & スタンプラリー

全国7地域（53社寺・霊場）および5大テーマ別スタンプラリーコースを収録した、スマホ・LINE LIFF対応の和風モダンWebアプリケーションです。

- **本番環境 (Vercel):** https://rekitabi-app.vercel.app
- **GitHub リポジトリ:** https://github.com/abeyuuki-hue/rekitabi-app

## ✨ 主な機能

1. **🗾 全国7地域・53社寺パワースポット御朱印帳 (`StampGrid`)**
   - 北海道・東北（6社寺）、関東・千葉（14社寺）、中部・甲信越・北陸（8社寺）、関西・近畿（11社寺）、中国（4社寺）、四国（4社寺）、九州・沖縄（6社寺）の全53スポットを収録。
   - 社寺名・都道府県・御祭神・ご利益（金運、縁結び、厄除け、勝運、学業成就など）によるリアルタイム検索に対応。
   - 現地500m以内のGPSチェックイン押印に加え、ヘッダーの **「🧪 テスト押印」** トグルでどこからでも押印・称号獲得の動作確認が可能。

2. **🏆 5大テーマ別スタンプラリーコース & デジタル称号授与**
   - `COURSE-001`: 全国最強金運・財運上昇めぐりコース（称号：**金運成就マスター**）
   - `COURSE-002`: 良縁成就・恋愛・人生の縁結びコース（称号：**良縁成就マスター**）
   - `COURSE-003`: 強運・厄除け・決断の勝負運コース（称号：**強運開拓の覇者**）
   - `COURSE-004`: 学業成就・合格祈願・自己研鑽コース（称号：**大願成就の賢者**）
   - `COURSE-005`: 日本総氏神・神話と霊峰の巡拝グランドコース（称号：**パワースポットグランドマスター**）

3. **🗺️ 古今絵図・和風マップ (`MapView` / `MapInner`)**
   - 国土地理院淡色地図タイル＋和風セピアフィルター＋マーカークラスタリング対応。
   - 参拝・押印済みの社寺には黄金の「💮」印が表示され、地域別・コース別のマップ絞り込みが可能。

4. **📔 参拝の記録帳 (`SanpaiLogList` / `DetailModal`) & ⛩️ 由緒・参拝作法ガイド (`WorshipGuide`)**
   - 各社寺の歴史・由緒、門前名物グルメ、御祭神、ご利益、参拝時間、特別な参拝作法（出雲大社の二礼四拍手一礼や伊勢神宮の外宮先祭など）を網羅。
   - 参拝日・天候・祈願内容・五段階評価を記録できるデジタル参拝日記機能を搭載。
